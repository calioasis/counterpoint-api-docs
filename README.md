# Counterpoint Salesforce API documentation

Published reference: https://calioasis.github.io/counterpoint-api-docs/

## Source of truth

`openapi.json` in this repository is the canonical published integration contract. The website renders it directly; its download is the same file. Other copies and emailed attachments are snapshots. API implementation remains in the Counterpoint backend repository.

## Updating the contract

1. Implement and test the API change in the backend. Do not document proposed behavior as deployed.
2. Update this repository’s `openapi.json` to match the deployed release; preserve v1 compatibility or introduce a separately agreed version.
3. Update `changelog.html` with the date, version, and compatibility impact.
4. Open a pull request and review the contract diff. After merge to `main`, validation and GitHub Pages deployment run automatically.
5. Confirm the published site/download and notify consumers of material changes through an approved message.

No automated backend deployment occurs when documentation changes. Backend changes do not silently republish the contract: release work must include this repository. This avoids publishing an unreviewed interface.

## Local preview

Run `python3 validate.py`, then `python3 -m http.server 8080` in this directory.

## Contents

- `openapi.json`: schemas, examples, authentication, and integration guide.
- `index.html`, `site.js`, `site.css`: reference shell; field tables are generated by Redoc from the specification.
- `changelog.html`: published release notes.
- `vendor/`: pinned Redoc 2.5.4 renderer and its license; no live CDN dependency.
- `.github/workflows/pages.yml`: validate and deploy.

This is a public documentation repository. Never add API keys, retrieval links, passphrases, production records, internal operational notes, or backend source code.

The landing page shows request JSON and required-field tables generated from openapi.json. After changing the contract or quickstart template, run `python3 build.py` and commit index.html. CI checks that it is current. Full Redoc documentation is at reference.html.
