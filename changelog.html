Changelog

Documentation follows released API behavior. The OpenAPI specification contains the current field-level contract; Git history preserves each revision.

1.0.0 · October 11, 2026

  • Initial published Salesforce Event and Task contract.
  • Authenticated sandbox access, restricted wholesaler and fictional advisors.
  • Event creation with asynchronous Outlook delivery and source-ID status lookup.
  • Completed Sales Activity creation without an Outlook appointment.
  • Persistent request UUIDs, duplicate-request recovery, structured errors, and correlation IDs.

Compatibility

Compatible additions can remain in /v1. Removing fields, changing their meaning, or introducing new required fields is a breaking change and requires a new agreed API version and migration period. Proposed features are not published as implemented behavior.

Before publishing a change

Verify the implementation is deployed, update openapi.json, add a changelog entry, and merge the reviewed change to main. GitHub Pages publishes the same specification used to render the reference.
